# 제2의 딥시크? 구글 터보 퀀트 쇼크, 자세히 알아봅시다!

​
이제 우리가 지금 당장 알아야 할 또 다른 중요한 이슈, 구글 터보 퀀트(Turbo Quant)를 설명해드리겠습니다. 지금 일부 빅테크와 삼성전자, SK하이닉스의 주가에 타격을 준 이슈이기 때문입니다.

메모리와 하드디스크를 만드는 샌디스크(SNDK)와 웨스턴 디지털(WDC) 주가는 -11~20% 떨어졌습니다. 구글 터보 퀀트 때문입니다.
사진 출처: 구글
정말 간단히 말하면 구글 터보 퀀트라는 새로운 기술 때문에 예전처럼 고성능 메모리들이 필요가 없게 되었다! 라는 우려인데요, 이번에도 지나친 공포일지 아니면 뭔가 근거가 있는 건지를 자세히 살펴보겠습니다.
기술이 주가와 심리에 주는 영향을 이해하려면 기술을 먼저 이해해야 합니다. 제가 공부해보니 조금 어려운 내용이지만, 정말정말 쉽게 최대한 풀어서 설명드리겠습니다.
사진 출처: geekboots
지금까지 AI는 대화를 길게 이어갈수록 머릿속에 계속 메모를 쌓아두는 구조였는데 그 메모가 엄청 무거웠습니다. 이 메모를 캐시(Cache)라고 합니다.
​
그런데 구글이 "그 메모를 거의 공짜 수준으로 가볍게 줄이는 방법을 찾았다" 라고 주장하면서 터보 퀀트를 내놓았던 거고요.
​
조금 더 자세하게 말하면 이렇습니다.
사진 출처: 포인트오브뷰
이 캐시라는 것이 한 번 읽은 내용은 다 저장해놓고 필요할 때 꺼내 쓰는 방식인데, 문제는 이 노트가 계속 두꺼워진다는 데 있습니다.
질문이 길어질수록, 대화가 길어질수록 노트가 점점 쌓입니다. 그래서 결국 이걸 다 들고 다니려면 가방을 계속 키워야 한다는 논리가 나오겠죠. 이게 바로 HBM, DRAM, SSD 같은 메모리 수요 증가 스토리였습니다.
그런데 터보 퀀트는 뭐냐면...
학생:
노트를 1/6로 압축했는데도 내용은 그대로 기억할 수 있게 되었어요!
​
이런 상태가 된 겁니다. 심지어 노트에서 필요한 내용을 더 빨리 찾을 수 있게 되었습니다.
​
예전: 노트 많음 → 가방 크게 필요 → 메모리 많이 필요
지금: 노트 압축됨 → 가방 작아도 됨 → 메모리 덜 필요할 수도 있음
사진 출처: john brandt
이게 어떻게 가능한가 하면, AI가 캐시에 저장하는 건 결국 숫자 덩어리입니다.
​
단어 하나를 처리할 때마다 이 단어가 어떤 의미였는지를 벡터라는 숫자 묶음으로 저장해두는데 이게 보통 16비트, 32비트 같은 꽤 정밀한 숫자로 저장됩니다.
​
문제는 여기서 이미 낭비가 많다는 겁니다. 실제로는 그렇게까지 정밀할 필요가 없거든요. 사람으로 치면 "오늘 점심 뭐 먹었지?" 라는 내용을 기억할 때 식당의 GPS 좌표 단위까지 기억할 필요 없고 "김치찌개 먹었다" 정도만 기억하면 되는 거랑 똑같습니다.
​
그래서 터보 퀀트의 첫 번째 핵심이 양자화(quantization)입니다.
​
쉽게 말하면 숫자를 대충 저장하는 겁니다. 16비트로 저장하던 걸 3비트 정도로 줄여버립니다. 당연히 정보가 일부 날아가야 정상인데 여기서 구글은 신박한 방식을 썼습니다.
​
구글:
그냥 막 줄이지 말고 AI가 실제로 중요하게 쓰는 정보만 남기고 나머지는 깔끔하게 날리자.
​
그래서 정확도가 거의 안 떨어진다고 주장하는 겁니다.
​
기존 양자화는 문제가 하나 있었습니다. 숫자를 줄이면 대신 이 숫자가 어떤 기준으로 줄여졌는지를 설명하는 보조정보가 붙습니다.

제가 기억한 정보들 중에 식당 좌표나 식당 사업자등록번호는 중요하지 않은 거 같으니까 날렸고 김치찌개 먹었다는 내용이 중요한 거 같아서 김치찌개 먹었다는 것만 남겼어요. 그러니까, 김치찌개를 먹었어요.
​
저 앞부분 설명이 대답보다 더 길죠? AI는 이걸 스케일, 제로포인트 이런 걸로 저장하는데 이게 은근히 용량을 잡아먹습니다. 쉽게 말해서 압축했는데 설명서가 더 두꺼워지는 상황입니다.
​
터보 퀀트는 여기서 그 설명서 자체를 없애거나 극단적으로 줄여버리는 방식을 씁니다. 이게 QJL, PolarQuant 계열에서 나온 아이디어인데 데이터를 표현하는 방식을 바꿔서 애초에 설명서가 필요 없게 만든 겁니다.
​
사람으로 치면 "키 180cm" 라고 쓰는 대신 "평균보다 큼" 이런 식으로 표현 체계를 바꿔버리는 느낌입니다.
​
마지막으로 KV 캐시는 사실 100% 중요한 정보가 아닙니다. 우리 사람끼리의 대화를 생각해보세요. 대화가 길어질수록 앞쪽 정보는 쓸 데가 없으니 영향력이 점점 줄어듭니다. 근데 기존 방식은 이걸 처음부터 끝까지 고스란히 저장하니까 문제가 생기겠죠.
터보 퀀트 계열 접근은 여기서 시간이 오래 지난 대화나 계산의 정보, 즉 점점 덜 중요해지는 정보는 더 강하게 압축하거나 대충 저장합니다. 그러니까 중요한 부분은 살리고 덜 중요한 부분은 과감하게 날리는 겁니다.
정리하면 이렇게 됩니다.
​
숫자를 더 대충 저장한다 = 용량 감소
압축할 때 붙던 설명서를 없앤다 = 추가 절감
중요도 낮은 정보는 더 강하게 줄인다 = 추가 절감
​
이 세 개가 합쳐지면서 메모리 필요량 1/6 같은 숫자가 나오는 겁니다. 여기서 시장이 바로 계산기를 두드렸습니다.
​
시장:
어? 그럼 우리가 생각했던 메모리 폭증 시나리오가 사실은 필요없이 과한 거 아니냐?
​
이 순간 삼성전자, SK하이닉스, 샌디스크, 웨스턴디지털 같은 기업들이 타겟이 되었습니다. 얘네는 바로 그 메모리라는 가방을 만드는 기업이니까요.
​
아까도 말씀드렸듯 AI는 생각이나 연산보다 기억력이 더 문제입니다. AI랑 대화가 길어지면 자꾸 앞에서 한 얘기를 까먹는 거, 많이들 겪어보셨죠? 이게 기술적 문제 때문입니다. 계산은 GPU가 잘하는데, KV 캐시가 자꾸 쌓이는 것, 이게 AI 서비스 비용의 숨은 주범입니다.
​
우리가 돈을 내는 건 아니지만 질문이 길어지면 AI 비용이 확 튀는 이유가 여기 있습니다.
​
그래서 시장은 AI가 커질수록 메모리 수요도 같이 폭발한다고 믿고 있었는데 터보 퀀트는 그 믿음을 제대로 건드린 거구요.
그럼 메모리 수요가 줄어들까, 아니면 AI 수요가 늘어날까?
저는 둘 다라고 봅니다. 오히려 역으로 생각하면, 메모리가 덜 필요해지면 AI 서비스 비용이 내려가겠죠. 그러면 기업들은 "어, 좋네? 그럼 더 많이 써버리자" 이렇게 갑니다. 결국 사용량이 폭증하면 총 메모리 수요는 다시 늘어날 수도 있습니다.
​
이게 약간 전기값이 싸지면 사람들이 전기를 더 쓰는 것과 비슷한 구조입니다.
터보 퀀트가 줄이는 건 AI 전체 메모리가 아니라 추론할 때 잠깐 쓰는 기억 공간(KV 캐시) 딱 그 한 부분입니다. AI가 돌아갈 때 메모리가 쓰이는 구간은 여러 개가 있는데 KV 캐시는 그중 하나일 뿐입니다.
예를 들어 AI의 전체 시스템을 일하는 사람의 환경으로 비유하면 어떨까요?

​
터보 퀀트는 이 중에서 메모장만 얇게 만든 거지, 뇌를 줄인 것도 아니고 책상이나 서랍을 없앤 것도 아닙니다. 그러니까 메모리 산업 전체가 타격 받는다는 해석은 좀 과장되었다고 봐야겠죠.
​
그리고 AI는 생각보다 메모리를 여기저기 다 씁니다.
​
모델 자체를 올려두는 데도 메모리가 필요하고, 계산 중간 결과도 저장해야 하고, 여러 사람이 동시에 쓰면 그걸 관리하는 메모리도 필요하고, 데이터를 불러오고 저장하는 과정에서도 메모리가 계속 개입합니다.
​
특히 요즘 AI는 여러 단계로 나눠서 작업하고 외부 데이터를 가져오고 다시 계산하는 식이라서 메모리를 쓰는 구간이 훨씬 많아졌습니다.
​
그래서 KV 캐시 하나 줄였다고 해서 전체 메모리 수요가 확 줄어든다고 보긴 어렵습니다. 쉽게 말하면 집에서 책상 위에 있는 노트 한 권 줄였다고 해서 집 크기를 줄일 수 있는 건 아니라는 얘기입니다.
야 그러면 반대의 논리도 적용되는거 아님? 그러니까, 효율이 좋아진다고 수요가 갑자기 6배로 뻥튀기될 수도 없지 않나?
사실 이 부분도 중요합니다. 터보 퀀트는 아까 말씀드린 수많은 병목들 중 KV 캐시라는 한 구간만 풀어준 거고 나머지는 그대로입니다.
​
GPU 연산, 네트워크 대역폭, 전력, 데이터 파이프라인, 소프트웨어 스택 다 그대로 병목 상태에 걸려 있는 겁니다. 노트는 가벼워졌는데 아직도 CPU는 느리고 인터넷은 막혀 있고 전기세는 비싼 상황입니다. 이런 상태에서 수요가 6배로 튀기도 좀 어렵겠죠.
​

...물론 희망회로였고 실제로는 품질, 범용성, 안정성에서 바로 한계가 드러나면서 기존 빅테크 스택이 유지됐습니다. 그래서 엔비디아, 메모리, 데이터센터 스토리는 멀쩡히 잘 살아남았습니다. 딥시크는 일종의 대체 가능성이었는데, 결국 대체가 안 됐습니다.

근데 터보 퀀트는 대체가 아니라 지금 쓰는 시스템을 바로 더 싸게 돌리는 방법입니다.

개인적으로는 샌디스크, 웨스턴 디지털, 삼성전자, SK하이닉스가 빠지는 건 이해할 수 있는데(어쨌든 일부 비용이 절감되는 건 사실이므로) 이것 때문에 빠지는 건 아닌 것 같습니다.
그냥 핑계 같아요. 이미 많이 올라서 주가 차익 실현을 하기 위한 핑계로 빼는 거죠. 이게 나왔다고 메모리 기술의 종말이니 뭐니 하고 어렵게 생각할 필요 없고, 기술은 기술이고 차익실현 핑계는 핑계입니다.
개인적으로는 이렇게 생각합니다. 메모리를 더 쓰냐, 덜 쓰냐가 중요한 게 아닌 것 같아요.
